# AI Generation Prompts

Prompts to run in Claude (or another LLM) to auto-generate YAML, system prompts, and eval cases. Copy the prompt, fill in the placeholders, and paste into Claude Code or the Claude web app.

| File | What it generates |
|------|------------------|
| `generate-topic.md` | Complete `.topic.mcs.yml` from a plain-English scenario |
| `generate-agent-instructions.md` | System prompt for `agent.mcs.yml` |
| `generate-adaptive-card.md` | Adaptive card JSON from a description |
| `generate-eval-cases.md` | Routing accuracy eval test cases |
| `review-agent.md` | Agent quality review checklist |
| `prompt-engineering-patterns.md` | P1–P10 pattern reference for system prompt design |

→ Claude skills that use these prompts directly: [`../../SKILLS-REFERENCE.md`](../../SKILLS-REFERENCE.md)
